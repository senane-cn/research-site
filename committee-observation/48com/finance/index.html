长期序列 · 8个双年度 · 2026.07.31

资金回到原位，结构已经改变

16年间，全来源资金只增长1.7%；核心常规预算反而下降0.9%。

2024—2025的明显回升主要来自专户、预算外资源和特定程序追加。保护仍是最大用途，但能力建设、申报准备和初步评估吸收了更多资源。长期问题不是“有没有钱”，而是稳定、可自由支配的钱能否跟上名录与法定任务扩张。

READING GUIDE / 读图方法

总额、稳定性与用途必须分开看

01 / CORE

先看核心

最终Total A代表最稳定的法定工作底盘；专户不能自动替代自由支配收入。

02 / SOURCE

再看来源

全来源回升可能来自指定用途资金，不能据此推断长期资源基础扩大。

03 / USE

再看用途

行动2总量相近，不代表保护投入未变；内部结构已经明显重组。

04 / OUTCOME

最后看结果

财务执行只能说明钱花到哪里，必须接上活动、制度产出与长期保护结果。

02 / FUNDING MIX

全来源总额回到原位，稳定性并未同步恢复

2016—2017触及2,904.10万美元低点，2024—2025回升至4,176.83万美元；但与2010—2011相比只增长1.7%。现在的世界遗产基金份额中，专户已占53.8%，多有指定用途。

不能把“总量恢复”直接写成“核心财力增强”

世界遗产基金核心收入主要是缔约国依《公约》第16条缴纳的强制性或分摊自愿会费；专户、自愿捐款和预算外资源通常受项目或主题约束。

CONTEXT / UNITED STATES

美国停缴造成的是直接缺口与早期预算压力，不是“后来总额回升就等于没有影响”

  1. 世界遗产基金：美国采用第16.2条分摊自愿会费方式；历届会费表持续把最后付款日列为2011年10月17日。
  2. UNESCO正常预算：2011年停缴后，组织整体预算在2012—2015进入紧缩；世界遗产两类稳定资金同期均下移，但本序列不能把所有降幅都归因于美国。
  3. 后期缓冲：预算调整、其他成员支持和指定资金多元化吸收了部分冲击，却没有形成同等稳定的核心收入。

03 / USE OF FUNDS

行动2总量几乎未变，钱的用途已经重组

行动2指遗产识别、保护、监测、能力建设、公众和社区参与等公约实施活动。其全来源支出端点只增长2.1%，但保护、管理和监测名义下降24.8%。

CAPACITY / 278.41万美元

能力建设不是单一培训费

包括遗产地管理者论坛、定期报告工作坊、管理有效性、影响评估、灾害风险、气候行动、数字记录、导师计划和区域行动计划实施。

COMMUNITY / 49.21万美元

社区参与高度依赖自愿资金

可涉及权利人参与、地方知识、青年与社区网络、生计和收益共享。2024—2025该类别全部来自自愿／预算外资源，持续性更易受捐助周期影响。

04 / EVALUATION FINANCE

从临时追加到专户分担，申报评估形成新的融资链

早期ICOMOS追加主要反映文化遗产案件量超过预算假设，并不能证明机构“自身没钱”。2019年后，正式提名评估缴款和强制性初步评估逐步形成新的专户机制。

    PRELIMINARY ASSESSMENT

    初步评估支出156.73万美元

    初步评估是在完整申报前，由ICOMOS、IUCN开展的强制性案头评估；国内讨论也常称“预评估”。它不等于正式提名评估，也不是一项由所有申报国按件全额支付的统一强制收费。

    核心基金19.91万美元 · 12.7% 评估专户136.82万美元 · 87.3%

    05 / INTERNATIONAL ASSISTANCE

    覆盖扩张进入平台期，平均项目规模开始回落

    2016—2025累计批准212项、667.44万美元。批准项目由26项增至50项，受援国家增至40个；最近三个双年度金额稳定在约153万—159万美元。

    正式批准额反映申请审批，不等于当期现金支出，也不能与议程12的全来源国际援助执行额直接相减。

    06 / MONEY TO OUTCOMES

    财务执行不能独自证明保护成效

    现有制度可以说明钱从哪里来、花到哪类活动；第三轮定期报告的43项指标则观察保护、管理和治理等长期变化。二者之间仍缺稳定的项目—遗产地—结果连接。

    METHOD / SOURCES

    资料、口径与解释边界

    金额均为名义美元。来源数据优先采用委员会闭幕年度决算和获批准国际援助统计；跨期预算外支出按当年实际支出重建完整双年度。

    核心边界

    • 每项遗产对应Total A只是制度负荷代理，不是平均拨款。
    • 分类名称历年变化，行动2细分只作端点方向判断。
    • 执行额、批准额与现金支付不是同一统计量。
    • 资金相关性不等于因果归因。
